# Abiotic Extended Modding Docs

**Abiotic Extended** (ABE) is a collection of tools and documentation for making mods for *Abiotic Factor*, using UE4SS, Unreal Editor and JSON.

This site documents how to install mods, how to get started making mods, and how to use the different tools and templates.
